# Junior — мобил виджет макетлари

Junior IT Academy иловасининг бош экрани учун виджет карточкалари ва панеллари.

**Кўриш:** https://azimovamunisa0322-sys.github.io/junior-vidjet-maketlar/

Саҳифада чапда телефон, ўнгда бошқарув панели. Карточкадаги тугмани босганда пастдан панел очилади. «Галерея» тугмаси барча ҳолатларни бирданига кўрсатади.

## Нима бор

| Виджет | Карточка ҳолати | Панел |
|---|---|---|
| Вебинар | 10 | 3 |
| Бандлов (Demo Day, қўшимча дарс) | 11 | 16 |
| Тўлов | 9 | 10 |
| Ментор | 7 | 7 |
| Стрик | 8 | 7 |
| Кунлик вазифалар | 9 | 8 |
| Тавсия этилган курс | 5 | 5 |

Жами 66 карточка ҳолати ва 66 панел. Ҳар бирида юкланиш ва хато ҳолати ҳам бор.

## Дастурчи учун

`spec/` папкасида ҳар виджет учун спецификация: ўлчамлар, ранглар, шрифт, ҳар ҳолатнинг ўзбекча ва русча матни, тугмаларнинг босиш зонаси, панеллар жадвали ва Flutter изоҳлари.

Асосий қоидалар: карточка 297×171 pt, шрифт SF Pro, бренд ранги `#FF4F28`. Карточкада қисқа хулоса ва битта тугма, тафсилотлар панелда.

## Эслатма

Бу дизайн макети, ишлайдиган илова эмас. Маълумотлар намуна учун ёзилган.

## Бугунги режа бўлими

`Salom!` баннери билан `O'yinlar` орасида **«Bugungi reja»** бўлими бор —
веб бош саҳифасидан (`junior-academy.vercel.app`, «2. Bugungi reja») кўчирилган:
`0/4 dars` ҳалқаси, «Bugun sizni uzoq kutdim!», `+300 coin` (қулфланган),
бугунги 3 та дарс, йиғиладиган «Barcha kurslarim» (11 та курс) ва
«Nega aynan shuncha dars?» изоҳи.

Макетнинг ўз дизайн тизимида чизилган — SFpro, `--c-brand`, `--r-card`,
16 px чеккалар. Виджетларга тегилмаган, улар фақат пастроққа сурилган.

Тахрирлаш: `bugungi-reja/into-maket/` да `plan.html`, `plan.css`, `plan.js`.
Ўзгартиргандан кейин:

```
python3 bugungi-reja/into-maket/apply.py
```

Скрипт бўлимни `index.html` га қайта жойлайди (эски нусхасини ўзи олиб ташлайди,
шунинг учун бир неча марта ишлатса бўлади). CSS **`</head>` дан олдин алоҳида
`<style>` блок** сифатида қўшилади — файлда `</style>` ўнлаб марта учрайди,
лекин улар JS сатрлари ичидаги экран шаблонлари, уларга тегиб бўлмайди.

Эски «Salom! ...» баннери бош экрандан **олиб ташланди** (2026-09-22).
Уни қайтариш: `git show 646f129:index.html` дан `<section class="banner">`
блокини олинг. Олиб ташлаш скрипти: `bugungi-reja/into-maket/remove_banner.py`.

Эски **«Kurslar»** бўлими ҳам олиб ташланди (2026-09-22) — унинг ўрнини
«Bugungi reja» ичидаги йиғиладиган «Barcha kurslarim» (11 та курс) эгаллади.
Скрипт: `bugungi-reja/into-maket/remove_courses.py`.

**«O'yinlar» бўлими** (2026-09-22): учта ўйин қатори — биринчиси очиқ
(`oyin/sanoq.html` ни очади), иккитаси қулфланган, босилса макетнинг ўз
`data-toast` пилюляси чиқади. Ҳар қаторда кун тоифаси чипи бор.
Скрипт: `bugungi-reja/into-maket/games.py` (қайта ишлатса бўлади).
Янги ўйин қўшиш — ўша скриптдаги `row(...)` қаторларига қўшинг.

**Бўлимлар тартиби** (2026-09-22): `logo → Bugungi reja → виджетлар → нуқталар → O'yinlar`.
Ўзгартириш: `bugungi-reja/into-maket/reorder.py`.

**Тепа қатор** (2026-09-22): лого чапда, ўнгда ўқувчининг умумий **coin (1703)**
ва **point (1673)** пилюлялари — веб версиядаги header каби. Улар аввал «Salom!»
баннери ичида эди. Иконкалар макетнинг ўзиникидан (`data-a="a8"`, `data-a="a20"`),
рақамлар `data-count` билан саналиб чиқади. Скрипт: `bugungi-reja/into-maket/topbar.py`.

## UI/UX сайқали (2026-09-24)

Профессионал аудит бўйича тузатилди. Ўлчовлар — саҳифанинг ўзидан:

| Нима | Аввал | Ҳозир |
|---|---|---|
| Контраст (WCAG AA дан ўтмайдиган матн) | 83 та | **19 та** (17 таси бренд ранги қарори) |
| 44px дан кичик тегиш майдони | 21 та | **0** |
| Ҳеч нима қилмайдиган тугма | 14 та | **0** |
| Чап тартиб чизиғи | 16 ва 23px | **ҳаммаси 16px** |

Қўшилган матн ранглари (ҳар қандай фонда 4.9+):
`--c-muted #5C6678`, `--c-brand-text #C2340D`, кўк матн `#0A6E9F`.
Фон ва тўлдиришлар тегилмаган — фақат матн тўқлашди.

`bugungi-reja/into-maket/polish.py` — мавжуд макет устидан ёзиладиган
қатлам. Уни ўчирса, макет аввалги ҳолига қайтади.

**Қолган 17 та — қарор талаб қилади:** оқ матн `#FF4F28` фонда 3.28
беради (AA учун 4.5 керак). Тузатиш учун тўлдирилган тугмалар ранги
`#D8390F` га туширилиши керак — бу бренд рангига тегади, шунинг учун
ўзим қилмадим.
