# Мобил виджет макетлари

Junior иловасининг бош экрани учун виджет карточкалари. Веб версия асосида, лекин илованинг ўз услубида қайта чизилган.

## Қандай кўриш

**Энг оддий йўл:** `MAKETLAR.html` файлини икки марта босинг, браузерда очилади. Бошқа ҳеч нарса керак эмас, ҳамма расм ва шрифт файл ичида.

Ичида иккита кўриниш бор:

- **Телефон** — карточкалар каруселда, ҳақиқий бош экран ичида. Ўнг томондаги рўйхатдан ҳар виджетнинг ҳолатини алмаштириб кўрасиз.
- **Галерея** — 66 та ҳолатнинг ҳаммаси бирданига, виджетлар бўйича гуруҳланган.

`render/` папкасида тайёр расмлар: телефон кўриниши ва ҳар виджетнинг ҳолатлари.

## Асосий қарорлар

1. **Ҳамма карточка бир хил ўлчам:** 297×171 pt, ички падинг 12. Каруселда ён томонга скролл, қўшни карточка 36 pt кўриниб туради.
2. **Карточка = қисқа хулоса + битта тугма.** Тафсилотлар пастдан чиқадиган панелда. Веб карточкаларнинг ҳеч бири 171 pt га сиғмайди, шунинг учун календарь, тескари саноқ ва рўйхатлар панелга кўчирилди.
3. **Битта тузилиш:** сарлавҳа қатори (ном, сана, ўнгда чип), тана (битта асосий факт), пастки қатор (битта апельсин тугма ёки изоҳ).
4. **Ранг маъноси:** апельсин = бренд ва асосий ҳаракат, яшил = бажарилди, кўк = маълумот, сариқ = танга, пушти-қизил = ўтказиб юборилди ёки хато, кулранг-кўк = ноактив. Веб'даги «ҳамма изоҳ пушти» қоидаси олиб ташланди.
5. **Ҳар бир боши берк ҳолат ёпилди.** Веб'да ўтказиб юборилган дарсда ёки блокланган тугмада ҳеч қандай йўл кўрсатилмас эди. Энди ҳар бирида сабаб ёзилган ва кейинги қадам таклиф қилинади.
6. **Матн иловадан:** «Mening bandlovlarim», «Kunlik vazifalar», «Joriy streak», «To'lov qilish». Ёзилиши «streak» ва «Demo Day».

## Файллар

```
MAKETLAR.html      ← кўриш учун шу файл, мустақил
index.html         ← ишлаб чиқиш версияси, локал сервер керак
cards/*.html       ← карточкалар, ҳар виджет учун битта файл
spec/*.md          ← дастурчи учун спецификация: ўлчам, ранг, ҳолат, матн, Flutter изоҳлари
css/tokens.css     ← ранглар, шрифт, ўлчамлар
css/card-base.css  ← карточканинг умумий класслари
render/*.png       ← тайёр расмлар
```

## Кейинги қадам

Пастдан чиқадиган панеллар ҳали чизилмаган. Уларнинг мазмуни ҳар спецификациянинг 5-бўлимида ёзилган. Энг муҳимлари: тўлиқ ой календари, Demo Day вақтини кўчириш, тўлов панели, ўтказиб юборилган дарс.

Дастурчидан ҳали керак: `homeDashboard.js` (карусел тартиби), `DailyChecklistWidget` ва `MonthlyChallenge` манбаси, веб таржима файллари.
