# Junior — мобил виджет макетлари

Junior IT Academy иловасининг бош экрани учун виджет карточкалари ва панеллари.

**Кўриш:** https://azimovamunisa0322-sys.github.io/junior-vidjet-maketlar/

Саҳифада чапда телефон, ўнгда бошқарув панели. Карточкадаги тугмани босганда пастдан панел очилади. «Галерея» тугмаси барча ҳолатларни бирданига кўрсатади.

## Нима бор

| Виджет | Карточка ҳолати | Панел |
|---|---|---|
| Вебинар | 10 | 3 |
| Бандлов (Demo Day, қўшимча дарс) | 11 | 16 |
| Тўлов | 9 | 10 |
| Ментор | 7 | 7 |
| Стрик | 8 | 7 |
| Кунлик вазифалар | 9 | 8 |
| Тавсия этилган курс | 5 | 5 |
| Фаоллик календари | 7 | 10 |

Жами 66 карточка ҳолати ва 66 панел. Ҳар бирида юкланиш ва хато ҳолати ҳам бор.

## Дастурчи учун

`spec/` папкасида ҳар виджет учун спецификация: ўлчамлар, ранглар, шрифт, ҳар ҳолатнинг ўзбекча ва русча матни, тугмаларнинг босиш зонаси, панеллар жадвали ва Flutter изоҳлари.

Асосий қоидалар: карточка 297×171 pt, шрифт SF Pro, бренд ранги `#FF4F28`. Карточкада қисқа хулоса ва битта тугма, тафсилотлар панелда.

## Эслатма

Бу дизайн макети, ишлайдиган илова эмас. Маълумотлар намуна учун ёзилган.

## Бугунги режа бўлими

`Salom!` баннери билан `O'yinlar` орасида **«Bugungi reja»** бўлими бор —
веб бош саҳифасидан (`junior-academy.vercel.app`, «2. Bugungi reja») кўчирилган:
`0/4 dars` ҳалқаси, «Bugun sizni uzoq kutdim!», `+300 coin` (қулфланган),
бугунги 3 та дарс, йиғиладиган «Barcha kurslarim» (11 та курс) ва
«Nega aynan shuncha dars?» изоҳи.

Макетнинг ўз дизайн тизимида чизилган — SFpro, `--c-brand`, `--r-card`,
16 px чеккалар. Виджетларга тегилмаган, улар фақат пастроққа сурилган.

Тахрирлаш: `bugungi-reja/into-maket/` да `plan.html`, `plan.css`, `plan.js`.
Ўзгартиргандан кейин:

```
python3 bugungi-reja/into-maket/apply.py
```

Скрипт бўлимни `index.html` га қайта жойлайди (эски нусхасини ўзи олиб ташлайди,
шунинг учун бир неча марта ишлатса бўлади). CSS **`</head>` дан олдин алоҳида
`<style>` блок** сифатида қўшилади — файлда `</style>` ўнлаб марта учрайди,
лекин улар JS сатрлари ичидаги экран шаблонлари, уларга тегиб бўлмайди.
